# VeritAZ

VeritAZ is a Chrome extension designed to detect potential AI generated text and deepfake indicators during Google Meet sessions.

## Features

• HUD based forensic monitoring  
• Deepfake detection overlay  
• AI text scanning system  
• Real-time dashboard  
• Google Meet integration  

## Technologies

HTML  
CSS  
JavaScript  
Chrome Extension Manifest v3

## Files

manifest.json – extension configuration  
popup.html – extension popup UI  
styles.css – HUD styling system  
mahika.html – dashboard interface
